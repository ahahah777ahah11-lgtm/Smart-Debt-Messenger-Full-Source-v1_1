# مرسال الديون الذكي — الإصدار 1.1.0

## ما تم فحصه في APK السابق
الملف السابق صغير جداً (حوالي 6 KB) ويحتوي على `classes.dex` بحجم 40 بايت فقط وJavaScript لا ينفذ إلا `console.log`، كما أن صفحة HTML تحتوي بيانات عملاء ثابتة ورسالة توحي بوظائف إرسال/تسليم غير مثبتة. لذلك لا يمكن اعتبار ذلك الملف نسخة تشغيلية مكتملة.

## الميزات في هذه النسخة المصدرية
- لوحة مؤشرات تحسب الأرصدة من البيانات الفعلية المحفوظة محلياً.
- إضافة/تعديل/حذف العملاء والبحث والتصفية حسب الرصيد والتأخير.
- تسجيل دفعة أو إضافة مبلغ مع تحديث الرصيد.
- التذكيرات حسب تاريخ الاستحقاق.
- فتح تطبيق SMS برسالة قابلة للمراجعة؛ لا يتم الإرسال بصمت ولا يدّعي التطبيق معرفة التسليم.
- سجل محلي لمحاولات فتح تطبيق الرسائل، واستيراد/تصدير CSV.
- أكاديمية مصغرة وقوالب رسائل وقراءة صوتية عند دعم الجهاز.
- التخزين عبر localStorage على الجهاز؛ احفظ نسخة CSV احتياطية دورياً.

## البناء عبر HTML to APK Builder
1. استخدم ملف `Smart-Debt-Messenger-HTML-Builder.zip`.
2. استورد ZIP من داخل تطبيق HTML to APK Builder. الملف `index.html` موجود في جذر ZIP وكل الموارد محلية.
3. اسم التطبيق: `مرسال الديون الذكي`، الحزمة المقترحة `com.smartdebt.messenger`، الإصدار `1.1.0`.
4. اضغط Build APK ثم ثبّت APK الناتج. قد تختلف أسماء الأزرار حسب إصدار الأداة.

## البناء عبر Klencod IDE / بيئة Android Gradle
يوجد مشروع Android WebView كامل داخل مجلد `android/`. افتح هذا المجلد كمشروع Gradle في بيئة تدعم Android Gradle Plugin 8.7.3 وJDK 17، ثم شغّل `assembleDebug`. يمكن أيضاً رفع المشروع إلى GitHub وتشغيل workflow الموجود في `.github/workflows/android-apk.yml` ثم تنزيل artifact.

## تنبيه مهم
- لا توجد بوابة SMS مدمجة، لذلك حالة التسليم الفعلية غير متاحة. يلزم مزود رسائل يدعم Delivery Reports وربط API آمن.
- لا يوجد استيراد مباشر لملفات PDF أو قواعد بيانات `.db` في هذه النسخة؛ استورد CSV بعد التحقق من الأعمدة.
- بياناتك محلية في WebView، وقد لا تنتقل تلقائياً إذا بنيت التطبيق بحزمة/أصل تخزين مختلف. صدّر CSV قبل التحديث.
- حزمة Android تحتاج تنزيل Gradle/Android SDK عند أول بناء، ولا يمكنني تأكيد نجاح بناء APK نهائي من هذه البيئة.
